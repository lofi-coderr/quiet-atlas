# Release policy

Current repository visibility: **Private**.

Public visibility is planned for the associated video publication. Keep the repository private until that publication and perform the visibility change only as a separate, explicitly approved release action.

The repository contains application source, tests, documentation, and required build configuration. Music, videos, background images, screenshots, generated maps, binaries, caches, dependencies, credentials, and private identifiers are excluded from Git history.

No deployment or GitHub Release publication is part of this source push.
